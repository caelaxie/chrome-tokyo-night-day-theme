# Tokyo Night Day — Chrome Theme

The [TokyoNight Day](https://github.com/mbadolato/iTerm2-Color-Schemes/blob/master/schemes/TokyoNight%20Day.itermcolors) color scheme applied to the Chrome UI.

## Install

1. Clone or download this repo:
   ```sh
   git clone git@github.com:caelaxie/chrome-tokyo-night-day-theme.git
   ```
2. Open `chrome://extensions` in Chrome.
3. Enable **Developer mode** (toggle, top right).
4. Click **Load unpacked**.
5. Select the `chrome-tokyo-night-day-theme` folder.

The theme applies immediately. To remove it, click **Remove** on the theme card at `chrome://extensions`.
